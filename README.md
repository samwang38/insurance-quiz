# 保險題庫 · 行動裝置保險業務員

行動裝置保險業務員資格測驗的題庫、練習與模擬考。純靜態網頁，可安裝到手機主畫面、可離線使用。

## 功能

- **練習模式** — 選科目與範圍（全部／沒做過／曾經答錯），作答後立即顯示答案與書上解析
- **模擬考** — 隨機抽題、倒數計時、時間到自動交卷，可設題數／時間／及格分數
- **錯題本** — 答錯自動收錄，答對自動移出，可依科目篩選、可重練
- **統計** — 題庫涵蓋率、各科掌握度、歷次成績
- **左右滑動切題**、可拖曳的題號導覽面板、深色模式、離線可用

共 2142 題，來源：

- 1022 題取自《行動裝置保險業務員資格測驗練習題》（中華民國產物保險商業同業公會）
- 1120 題取自證基會「金融市場常識與職業道德」官方題庫 113 年版（金融市場常識 504 題＋職業道德 616 題，已套用 113.9.23 修訂公告），科目名稱標註「(證基會)」

## 檔案結構

```
index.html              整個 App（HTML + CSS + JS + 題庫，單檔）
manifest.webmanifest    PWA 設定：名稱、圖示、啟動方式
sw.js                   Service Worker：離線快取與背景更新
icons/                  App 圖示
.nojekyll               告訴 GitHub Pages 原樣輸出，不要跑 Jekyll
```

沒有建置流程、沒有相依套件。改完直接 commit 就是新版。

## 本機預覽

Service Worker 需要 http 才會啟動，直接用 `file://` 開只能看畫面、不能測離線：

```bash
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000
```

## 資料保存

作答紀錄存在瀏覽器的 localStorage，只留在該裝置上，不會上傳到任何地方。清除瀏覽器資料或更換裝置後紀錄會消失。

## 更新題庫

題庫是 `index.html` 裡的 `const BANK = [...]` 陣列，每題格式：

```js
{ "subject": "保險法規", "num": 12, "page": 34,
  "q": "題目文字",
  "opts": { "A": "…", "B": "…", "C": "…", "D": "…" },
  "ans": "C",
  "exp": "解析文字，沒有就留空字串" }
```

改完記得把 `sw.js` 最上面的 `VERSION` 往上加一號，舊快取才會被換掉。
